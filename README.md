# Namma-Platform 🚉

Namma-Platform is an Android application designed to serve as a comprehensive railway assistant, specifically aimed at helping passengers navigating smaller train stations. 

## 🚀 Features

* **Live Train Information:** Access real-time updates and status tracking for arriving and departing trains.
* **Coach Layouts:** View easy-to-understand visual guides for train coach positions to help passengers wait at the correct spot on the platform.
* **Kannada Audio Assistance:** Provides localized voice guidance in Kannada to ensure accessibility and ease of use for regional passengers.

## 🛠️ Tech Stack

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
* **Design System:** Material Design 3 (Material You)
* **IDE:** Android Studio
